# Decision records

Short notes on *why* something is the way it is. Write one when you make a choice
you'd otherwise forget the reasoning for in six months.

Format: `NNNN-short-title.md`, using the template below.

```markdown
# NNNN — Title

**Date:** YYYY-MM-DD
**Status:** accepted | superseded by NNNN

## Context
What situation forced a decision.

## Decision
What I chose.

## Consequences
What this makes easy, and what it makes hard or costs later.
```
